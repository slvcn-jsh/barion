# Benchmark methodology

Immutable source artifacts feed frozen concept inventories, cards, claims, grounding, citations, risk, selective verification, pedagogy, publication policy, coverage, and comparison.

Development/validation/holdout assignment is deterministic and disjoint. Holdout access is recorded and occurs only after validation passes. Experiments permit one intervention and record root cause, deltas, decision, and rationale. Safety, grounding, critical coverage, and citation regressions veto acceptance.

Model comparison hides provider/model identity. Same-family generator/evaluator overlap must be disclosed; SOL self-consistency is not independent-rater agreement. Cost reports preserve unknown currency costs rather than inventing prices.

Governed corpus registry covers psychiatric nursing, general nursing, pharmacology, dentistry, anatomy, physiology, pathology, and microbiology with project-authored CC0 fixtures. Registry tracks source hash, version, structure, numeric/medication density, risk, concept inventory, and reference availability.

Current canonical experiment re-evaluates unchanged cards with deterministic UTF-16 spans. No paid regeneration occurred. It tests citation provenance intervention, not generator-model superiority.
