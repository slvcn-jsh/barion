# Bari 3D Components

This folder contains repository starter files for integrating Bari as a 3D mascot.

## Files
- `BariModel.types.ts` — shared props contract
- `BariModel.web.tsx` — web starter using a model-viewer style boundary
- `BariModel.native.tsx` — native placeholder boundary

## Important note
These files are intended to make repository integration cleaner and faster.
They are a starter pack, not the final runtime implementation.
