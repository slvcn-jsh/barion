# Barion Bari 3D Repository Starter Pack

This package is meant to be copied into the Barion repository.

## Included
- repository-ready Bari 3D files
- integration docs
- animation specs
- starter component boundaries

## Best use
1. commit the asset and docs first
2. review Bari internally
3. decide the runtime strategy
4. upgrade to a rigged/animated production GLB later
