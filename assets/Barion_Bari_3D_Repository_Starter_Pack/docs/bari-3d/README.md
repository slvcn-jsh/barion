# Bari 3D Repository Pack

This folder is a repository-ready starter pack for Bari, the Barion AI learning companion.

## What is included

- A real **static 3D Bari prototype** in `.glb`, `.obj`, and `.ply`
- A **repository manifest**
- A **production animation specification**
- A **behavior and interaction specification**
- A **Barion integration guide**
- A **web integration starter component**
- A **shared state / animation constants file**

## Important limitation

This pack is **not yet a final production character pipeline**.
The current 3D asset is:

- real
- usable
- importable
- repository-ready

but also:

- static
- non-rigged
- non-animated

Use this pack as the Bari 3D foundation for the Barion repository.
